# E-Commerce Store

A full-stack e-commerce web application with a modern frontend and REST API backend.

## Features

* User registration and authentication
* Product browsing and product details
* Shopping cart functionality
* Order management
* Responsive user interface
* RESTful backend APIs
* MongoDB database integration
* Secure environment-based configuration

## Tech Stack

### Frontend

* Next.js
* React
* JavaScript
* CSS

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose

## Project Structure

```text
e-commerce-store/
├── e-comerce-frontend/
└── e-comerce-backend/
```

## Installation

Clone the repository:

```bash
git clone https://github.com/Gaurav-coder-tech/e-commerce-store.git
cd e-commerce-store
```

Install dependencies for the backend:

```bash
cd e-comerce-backend
npm install
```

Install dependencies for the frontend:

```bash
cd ../e-comerce-frontend
npm install
```

## Environment Variables

Create the required `.env` files in the backend and frontend directories and configure the required database and application settings.

Do not commit credentials, API keys, database passwords, or other sensitive information.

## Running the Application

Start the backend:

```bash
cd e-comerce-backend
npm run dev
```

Start the frontend in another terminal:

```bash
cd e-comerce-frontend
npm run dev
```

The application will then be available through the local development URL shown by the frontend development server.
